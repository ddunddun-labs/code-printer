# Code Printer

[[English]](./README.md) | **[한국어]**

소스 코드를 아름답게 인쇄하세요. 이 웹 애플리케이션을 사용하면 코드를 붙여넣고, 스타일을 지정하고, 브라우저 내에서 A4 크기 레이아웃으로 인쇄할 수 있습니다.

## 주요 기능

-   **실시간 인쇄 미리보기**: 코드가 종이에서 어떻게 보일지 정확하게 확인할 수 있습니다.
-   **다단 레이아웃**: 1단 및 2단 레이아웃을 모두 지원합니다.
-   **구문 강조**: 다양한 테마로 코드 가독성을 유지합니다.
-   **자유로운 커스터마이징**: 글꼴, 여백, 줄 간격 등을 자유롭게 조정할 수 있습니다.
-   **찾기 및 바꾸기**: 코드 내용을 쉽게 변경할 수 있습니다.
-   **100% 브라우저 기반**: 코드가 서버로 전송되지 않습니다. 모든 작업은 개인 정보 보호를 위해 브라우저 내에서 로컬로 처리됩니다.

## 사용 방법

1.  [Code Printer 웹사이트](https://simpl.github.io/print-source)에 방문합니다. <!-- 배포 후 이 URL이 작동합니다 -->
2.  에디터에 코드를 붙여넣습니다.
3.  컨트롤 패널을 사용하여 스타일 옵션을 조정합니다.
4.  브라우저의 인쇄 기능(Ctrl+P)을 사용하여 미리보기 페이지를 인쇄합니다.
