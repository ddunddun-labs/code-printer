# Code Printer Help

Code Printer helps developers print source code cleanly on A4 paper or save it as PDF.

## Quick start

1. Paste code into the editor or drag and drop a file.
2. Adjust language, font, margins, and columns in the preview controls.
3. Print with Ctrl+P / Cmd+P. Use **None** or **Minimum** margins and enable **Background graphics**.

## Page breaks

Manual page break marker (exact line):

```
%%%%%%%%%% PAGE_BREAK %%%%%%%%%%
```

## Data security

Your code is never uploaded. All processing happens locally in your browser.
